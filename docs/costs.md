# 외부 API 비용과 캐시 전략

1인 개발 + 무료 한도 안에서 운영하는 것이 전제였다. 그래서 외부 호출마다 "언제, 몇 번, 무엇으로 줄이나"를 정해 두었다. 단가는 바뀔 수 있어 아래 표에는 **호출 수와 토큰**을 적고, 요금은 각 제공자의 가격표를 기준으로 한다.

## 호출 요약

| 서비스 | 호출 시점 | 1회 일정당 | 캐시 / 장치 | 무료 한도 |
|---|---|---|---|---|
| Google Places Nearby Search (New) | 일정 생성 | 관광지 1 + 식당 날짜 그룹당 2 + 숙소 1 ≈ **6~10회** | 기기 7일. 중심 3km 안 날끼리 식당 검색 공유 | Enterprise SKU 월 1,000회 |
| Google Places Photo | 카드 사진(설정에서 켤 때) | 보이는 카드만 | 장소당 1장, 기기 캐시, 지연 로드 | — |
| SerpApi (Google Flights) | 일정 생성 | **0~1회** | 같은 노선·날짜 24시간. 실패·키 없음·한도 초과 → 예시 데이터(화면에 "예시" 표시) | 월 250회 |
| open.er-api.com | 일정 생성 | 1회 | 메모리 | 무료 |
| Open-Meteo | 일정 열람(D-7 안만) | 0~1회 | 좌표·기간별 6시간 | 비상업 무료 |
| Claude Haiku — AI 도우미 | 미리보기를 누를 때 | 문장당 1회(적용은 호출 없음) | 사용자당 분당 5회 | 유료 (토큰) |
| Claude Haiku — 일정 검토 | 검토 카드 펼칠 때 | 보통 1회 | 같은 문제는 다시 묻지 않음, 한도 공유 | 유료 (토큰) |

### 장소 필드는 필요한 것만

Places는 **요청한 필드에 따라 SKU(요금 등급)가 정해진다.** 평점·가격대가 필요해 이미 Enterprise 등급이므로, 같은 등급의 정기 영업시간(`regularOpeningHours`)은 단가를 올리지 않고 추가했다. 영업시간을 넣으면서 캐시 키는 바꾸지 않았다 — 바꾸면 기존 캐시가 전부 버려져 목적지마다 검색이 다시 나간다. 예전 캐시는 "영업시간 모름"으로 읽혀 휴무 검사만 건너뛰고, 7일 안에 저절로 채워진다.

## Claude 토큰 실측

에뮬레이터에서 실제 호출한 값(Cloud Functions 로그·앱 로그).

| 기능 | 입력 토큰 | 출력 토큰 | 비고 |
|---|---|---|---|
| AI 도우미 | 약 1,400 ~ 1,730 | 약 70 ~ 200 | 지시문 + 도구 정의가 입력의 대부분 |
| 일정 검토 (문제 1건) | 약 2,070 ~ 2,360 | 약 200 ~ 230 | 그날 일정 요약 + 사실 문장 |
| 일정 검토 (문제 2건, 이틀) | 약 2,560 | 약 440 | |

줄이는 장치:

- **사고(thinking) 끔, effort low** — 문장 하나를 명령 몇 개로 바꾸는 일이라 깊이 생각할 필요가 없다.
- **`max_tokens` 상한** — AI 도우미 512, 검토 1,024. 비용 상한으로도 쓴다.
- **별칭과 한 줄 요약** — 장소 id 대신 `a1`, JSON 대신 `a1 | 관광지 | 센소지 | buddhist_temple | 체류 90분 | 이동 15분 | 숙소 3.1km`.
- **문제를 한 번에** — 검토는 문제마다 따로 묻지 않고 한 요청에 모은다(지시문·도구 토큰을 한 번만 낸다).
- **규칙이 먼저** — 문제가 0건이면 카드 자체가 없고 호출도 없다.

## 실패해도 계획은 나온다

외부 호출 하나가 실패했다고 계획 전체를 실패시키지 않는다.

| 실패 | 대체 |
|---|---|
| 항공권 (키 없음·한도·네트워크) | 예시 항공 데이터 + "예시 데이터" 표시 — 예시 가격을 실제 요금으로 오해하지 않게 |
| 환율 | 내장 기본 환율 |
| 날씨 | 날씨 없이 표시(칩 아이콘·비 규칙만 빠짐) |
| Claude | "지금은 처리할 수 없어요" / 검토 카드는 규칙 기본 수정 |

## 키 보관

| 키 | 위치 |
|---|---|
| Maps·Places, SerpApi | `local.properties` (커밋 안 함) → BuildConfig |
| Anthropic | Firebase Secret Manager (`functions:secrets:set`) — 앱에는 없다 |
| Firebase 클라이언트 키 (`google-services.json`) | 저장소에 있음. APK에 그대로 들어가는 공개 식별자이고, Cloud Console에서 Android 앱(패키지 + SHA-1)·API 범위로 제한했다. 데이터 보호는 Firestore 보안 규칙이 한다 |
