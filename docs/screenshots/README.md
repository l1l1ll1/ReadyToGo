# 화면 캡처

보고서·포트폴리오에 쓰려고 남겨 둔 실행 화면이다. 코드에서 참조하지 않으므로
화면이 바뀌면 다시 찍어 덮어쓰면 된다.

| 파일 | 내용 |
|---|---|
| `icon.png` | 런처 홈 화면의 앱 아이콘 (독 오른쪽) |
| `splash.png` | 시작 화면 — 흰 배경에 로고 일러스트 |
| `login.png` | 로그인 — 흰 배경, 워드마크 + 소개 문구 |
| `home.png` | 홈 — 다가오는 여행 카드, FAB |
| `plan-summary.png` | 결과 화면 요약 탭 |

전부 한국어다. 앱 언어는 설정에서 바꾼다.

**찍은 환경**: 에뮬레이터 Pixel 9 / API 36.1(Android 16) / 1080×2424,
앱 언어 한국어, 글자 크기 보통, 고대비 끔.

접근성 설정을 켠 상태의 화면이 필요하면 설정에서 바꾸고 다시 찍는다 —
글자 크기와 고대비는 모든 화면에 바로 반영된다.
