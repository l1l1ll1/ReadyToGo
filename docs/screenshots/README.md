# 화면 캡처

보고서·포트폴리오에 쓰려고 남겨 둔 실행 화면이다. 코드에서 참조하지 않으므로
화면이 바뀌면 다시 찍어 덮어쓰면 된다.

| 파일 | 내용 |
|---|---|
| `icon.png` | 런처 홈 화면의 앱 아이콘 (독 오른쪽) |
| `splash.png` | 시작 화면 — 흰 배경에 로고 일러스트 |
| `login.png` | 로그인 — 민트그레이 바탕, 워드마크 + 소개 문구, pill 버튼 |
| `home.png` | 홈 — 인사말 + "다음 여행" 히어로(D-day·기간), 최근 일정 2열, 떠 있는 pill 탭바 |
| `settings.png` | 설정 — 계정·언어·알림·접근성 |
| `plan-summary.png` | 결과 화면 요약 탭 |
| `plan-timeline-photos.png` | 일정표 — 설정에서 "장소 사진 표시"를 켠 상태 |
| `plan-review.png` | 요약 탭 — 일정 검토 카드를 펼친 상태(비 오는 날 실외 관광지 2건, AI 설명) |
| `timeline-weather.png` | 일정표 — 날짜 칩 날씨 아이콘과 갱신 시각·출처 줄 |
| `map.png` | 지도 탭 — 일정표 순서 번호 핀(관광지 빨강·식당 주황), 숙소 → 순서대로 → 숙소 경로선 |
| `text-edit.png` | (옛 화면) 말로 일정 고치기 — "점심 라멘 말고"로 점심이 바뀐 직후 |
| `ai-helper.png` | AI 도우미 — "오후 하나 빼줘" 미리보기(빼기 1건), 적용 전 |
| `en-input.png` | 영어 — 입력 화면 (금액이 달러로 환산된다) |
| `en-plan-summary.png` | 영어 — 결과 화면 요약 탭 |
| `en-trips.png` | 영어 — 여행 탭 |

앱 언어는 설정에서 바꾼다. `en-`으로 시작하는 셋은 영어로 바꾼 뒤 찍었다 —
글자뿐 아니라 도시·나라·항공사 이름과 금액 표기까지 언어를 따라간다.

**찍은 환경**: 에뮬레이터 Readytogo_Shot / 1080×2424, 상태 표시줄 데모 모드(12:00),
날씨는 디버그 `weather_shift 53`으로 실제 예보를 여행 날짜에 옮겨 붙임(11/2 촬영),
글자 크기 보통, 고대비 끔.

접근성 설정을 켠 상태의 화면이 필요하면 설정에서 바꾸고 다시 찍는다 —
글자 크기와 고대비는 모든 화면에 바로 반영된다.
